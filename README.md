# 麻雀学習 Web アプリ

麻雀を初めて学ぶ人が、牌の見分け方、基本的な組み合わせ、あと1枚で組を完成させる考え方を、クイズや神経衰弱を通して楽しく身につけるための Web アプリです。

## ローカルで確認

読みの練習は「牌から読みを選ぶ」「読みから牌を選ぶ」に分け、各ステージ内の回答形式を統一しています。どちらも数牌と字牌を混ぜて出題します。

Node.js 24.22.1 以降を用意し、次を実行します。nvm を使う場合は `.nvmrc` のバージョンを選択してください。

```sh
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開いてください。学習ステージ、神経衰弱、牌一覧、麻雀辞典、成績、設定を操作できます。神経衰弱は6組（12枚）、12組（24枚）、最大26組（52枚）から選べ、最初は12組で始まります。スマホ幅（520px以下）では24枚までに制限します。最大モードでは34種類から26種類の牌を毎回選びます。「あと1枚で組を作る」ステージでは、提示された2枚に1枚足して刻子か順子を作る問題を出します。牌には `assets/tiles/Regular` の SVG を使用し、成績と表示設定はブラウザの `localStorage` に保存します。

### スマートフォン実機で確認する

PC とスマートフォンを同じ Wi-Fi に接続し、PC で次を実行します。

```sh
npm run dev:lan
```

PC の IPv4 アドレスを `ipconfig`（Windows）で確認し、スマートフォンのブラウザで `http://<PCのIPv4アドレス>:5173/` を開きます。スマートフォンの `localhost` はスマートフォン自身を指すため、PC のアドレスに置き換える必要があります。Windows のファイアウォールに確認された場合は、信頼するプライベートネットワークに限って Node.js の通信を許可してください。つながらない場合は、PC 側でも同じ LAN アドレスで開けるか、VPN や Wi-Fi の端末間通信制限がないかを確認します。開発サーバーは確認が終わったら `Ctrl+C` で停止してください。

麻雀辞典は用語と、雀魂の通常の四人麻雀で使う一般的な役を掲載します。名前・読み・説明で検索でき、分類や翻数で絞り込めます。用語の図は既存の牌SVGを使い、チー・ポンなどは画面内で動きを示します。項目は `src/data/encyclopedia.ts` で管理し、`groups` に牌の図、`media` に `assets/` 内の画像・GIFの公開パス（例: `/dictionary/pon.gif`）を指定できます。特殊ルールの役は対象外です。

ステージの問題候補は `src/data/questions.json` で管理します。各ステージの候補から挑戦ごとに重複しない5問を選び、選択肢の順番も変えます。「あと1枚で組を作る」ステージは両側・端・間・対子からの完成を毎回1問以上含めます。`reading` は牌の絵からカナの読みを選ぶ問題、`tileFromReading` はカナの読みから牌を選ぶ問題です。ヒントを出す問題だけ `hint` を設定します。

```sh
npm run check:domain
npm run check:content
npm run check:drills
npm run check:render
npm run build
```

初回公開の判断には、実際のスマートフォン・タブレット・PCで主要画面を操作して見た目と操作感を確認します。Figma は初期の参考案であり、画面を一致させることは公開条件ではありません。辞典の牌姿・基本問題とドリルの解答は上記の検査コマンドで確認できます。

## データと素材

アカウント登録やサーバーへの成績送信はありません。学習記録と表示設定は利用中のブラウザの `localStorage` に保存され、設定画面から学習記録を消去できます。別の端末には自動で引き継がれません。

画面表示には Google Fonts の Noto Sans JP を読み込むため、閲覧時に Google Fonts への通信が発生します。

牌の SVG は [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) に由来します。素材の説明と CC0 のライセンス文は [SOURCE_README.md](assets/tiles/SOURCE_README.md) と [LICENSE.md](assets/tiles/LICENSE.md) に保存しています。

## 今後の進め方

現状の機能を先行公開の候補とし、端末ごとの見た目と操作感、公開先での表示を確認します。問題や麻雀の説明を追加・変更した際は、内容のレビューと検査を繰り返します。将来は点数計算を基礎から学べる問題集を検討します。

## 待ち・何切るドリル

学習選択は「牌を覚える」「形を覚える」「待ち・何切る」の3カテゴリです。「手牌の中の基本形」は基礎レッスンと重複するため選択画面から削除しました。

- テンパイと待ち：刻子を含む10牌姿×6変形。両面・辺張・嵌張・単騎・双碰・多面待ち・ノーテンを含みます。
- テンパイにする何切る：10牌姿×6変形。今の14枚からテンパイへ進める打牌を選びます。成立する打牌はすべて正解です。
- 一向聴の何切る：専用の8牌姿×6変形。余分なターツ、雀頭候補、孤立牌などを比較し、一向聴を保つ打牌の中でテンパイへの受け入れ枚数を最大化します。

各回5問は異なる基本牌姿から選びます。素材は自作。テンプレートは `src/domain/drills.ts`、向聴数・完成形の判定は `src/domain/hands.ts`。4面子1雀頭を対象とし、七対子・国士無双や役・打点・守備は評価しません。受け入れは各4枚から手元の14枚（捨てる牌も含む）を引きます。

不正解メッセージとヒントは併記できます。「答えを見る・スキップ」で正答と解説を表示し、「次の問題へ」で進みます。答えを見た問題は正解数に含みません。旧「待ちを広くする何切る」の記録は一向聴の新レッスンに引き継ぎません。

`check:drills` は全168候補の枚数・回答判定・難易度条件・出題の重複を検査します。一向聴の代表牌姿は、向聴計算とは別に「ツモ→打牌→待ち牌」の列挙でも受け入れを照合します。
