# 麻雀学習 Web アプリ

麻雀を初めて学ぶ人が、牌の見分け方、基本的な組み合わせ、あと1枚で組を完成させる考え方を、クイズや神経衰弱を通して楽しく身につけるための Web アプリです。

## ローカルで確認

読みの練習は「牌から読みを選ぶ」「読みから牌を選ぶ」に分け、各ステージ内の回答形式を統一しています。どちらも数牌と字牌を混ぜて出題します。

Node.js 22 以降を用意し、次を実行します。

```sh
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開いてください。学習ステージ、神経衰弱、牌一覧、成績、設定を操作できます。「あと1枚で組を作る」ステージでは、提示された2枚に1枚足して刻子か順子を作る問題を出します。牌には `assets/tiles/Regular` の SVG を使用し、成績と表示設定はブラウザの `localStorage` に保存します。

ステージの問題候補は `src/data/questions.json` で管理します。各ステージの候補から挑戦ごとに重複しない5問を選び、選択肢の順番も変えます。「あと1枚で組を作る」ステージは両側・端・間・対子からの完成を毎回1問以上含めます。`reading` は牌の絵からカナの読みを選ぶ問題、`tileFromReading` はカナの読みから牌を選ぶ問題です。ヒントを出す問題だけ `hint` を設定します。

```sh
npm run check:domain
npm run check:drills
npm run check:render
npm run build
```

画面はローカル確認用の初期実装です。Figma との細かな照合と調整は続けます。

初回公開のレッスン構成、出題と解説の内容、進捗の扱い、画面デザインを相談して決めます。技術構成は学習体験に必要な範囲で選びます。

## 待ち・何切るドリル

学習選択は「牌を覚える」「形を覚える」「待ち・何切る」の3カテゴリです。「手牌の中の基本形」は基礎レッスンと重複するため選択画面から削除しました。

- テンパイと待ち：刻子を含む10牌姿×6変形。両面・辺張・嵌張・単騎・双碰・多面待ち・ノーテンを含みます。
- テンパイにする何切る：10牌姿×6変形。今の14枚からテンパイへ進める打牌を選びます。成立する打牌はすべて正解です。
- 一向聴の何切る：専用の8牌姿×6変形。余分なターツ、雀頭候補、孤立牌などを比較し、一向聴を保つ打牌の中でテンパイへの受け入れ枚数を最大化します。

各回5問は異なる基本牌姿から選びます。素材は自作。テンプレートは `src/domain/drills.ts`、向聴数・完成形の判定は `src/domain/hands.ts`。4面子1雀頭を対象とし、七対子・国士無双や役・打点・守備は評価しません。受け入れは各4枚から手元の14枚（捨てる牌も含む）を引きます。

不正解メッセージとヒントは併記できます。「答えを見る・スキップ」で正答と解説を表示し、「次の問題へ」で進みます。答えを見た問題は正解数に含みません。旧「待ちを広くする何切る」の記録は一向聴の新レッスンに引き継ぎません。

`check:drills` は全168候補の枚数・回答判定・難易度条件・出題の重複を検査します。一向聴の代表牌姿は、向聴計算とは別に「ツモ→打牌→待ち牌」の列挙でも受け入れを照合します。
