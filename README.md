# 麻雀学習 Web アプリ

麻雀を初めて学ぶ人が、牌の見分け方と基本的な組み合わせを、クイズや神経衰弱を通して楽しく身につけるための Web アプリです。

## ローカルで確認

Node.js 22 以降を用意し、次を実行します。

```sh
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開いてください。学習ステージ、神経衰弱、牌一覧、成績、設定を操作できます。牌には `assets/tiles/Regular` の SVG を使用し、成績と表示設定はブラウザの `localStorage` に保存します。

ステージの問題候補は `src/data/questions.json` で管理します。各ステージの候補から挑戦ごとに重複しない5問をランダムに選び、選択肢の順番も変えます。`reading` は牌の絵からカナの読みを選ぶ問題、`tileFromReading` はカナの読みから牌を選ぶ問題です。ヒントを出す問題だけ `hint` を設定します。

```sh
npm run check:domain
npm run check:render
npm run build
```

画面はローカル確認用の初期実装です。Figma との細かな照合と調整は続けます。
