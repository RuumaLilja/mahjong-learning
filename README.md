# 麻雀学習 Web アプリ

麻雀を初めて学ぶ人が、牌の見分け方と基本的な組み合わせを、クイズや神経衰弱を通して楽しく身につけるための Web アプリです。

## 現在の段階

学習体験と初回公開の内容を検討中です。実装はまだ始めていません。

## 資料

- [企画書](docs/brief/PROJECT_BRIEF.md) — 開発の背景と初期方針。詳細仕様は未確定です。
- [決定事項](docs/decisions/) — 合意した方針を、公開段階や大きなテーマごとに記録します。
- [検討事項](docs/questions/) — これから決めることを、公開段階や大きなテーマごとに整理します。
- [牌素材の資料](docs/assets/) — 素材の出典、内容、利用条件を記録します。

関連する話題は同じ資料にまとめ、段階が変わったり独立した設計が必要になったりしたら新しい資料を作ります。議論のたびにファイルやコミットを増やす必要はありません。

## 開発を始める前に

初回公開のレッスン構成、出題と解説の内容、進捗の扱い、画面デザインを相談して決めます。技術構成は学習体験に必要な範囲で選びます。
