# 麻雀学習 Web アプリ

麻雀を初めて学ぶ人が、牌の見分け方と基本的な組み合わせを、クイズや復習を通して楽しく身につけるための Web アプリです。

## 現在の段階

学習体験と初回公開の内容を検討中です。実装はまだ始めていません。

## 資料

- [企画書](docs/brief/PROJECT_BRIEF.md) — 開発の背景と初期方針。詳細仕様は未確定です。
- [決定事項](docs/decisions/) — 合意した方針を話題ごとのファイルに記録します。
- [検討事項](docs/questions/) — 未決定の論点を話題ごとのファイルに記録します。
- [牌素材の資料](docs/assets/) — 素材の出典、内容、利用条件を記録します。

決定や論点が増えたときは、対応するディレクトリに新しいファイルを追加します。単一の議事録や決定事項ファイルへ追記し続けない構成です。

## 開発を始める前に

初回公開のレッスン構成、出題と解説の内容、進捗の扱い、画面デザインを相談して決めます。技術構成は学習体験に必要な範囲で選びます。
